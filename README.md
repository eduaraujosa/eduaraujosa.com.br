# eduaraujosa.com.br

Site pessoal de Eduardo Araújo: ensino de Ciências, pesquisa em educação e design de experiências de aprendizagem.

Página única em HTML e CSS, sem framework nem etapa de build. Os textos ficam no `index.html`; as imagens otimizadas ficam em `img/`.

## Estrutura

- `index.html`: página inicial com apresentação, trajetória, pesquisa, prática, publicações, textos e contato.
- `img/`: fotos e logo em WebP. O `eduardo-retrato.jpg` é a imagem de compartilhamento (Open Graph), e o `apple-touch-icon.png` é o ícone para iOS.
